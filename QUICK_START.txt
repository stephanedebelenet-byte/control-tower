⏱️  ESTIMATED TIME: 30 minutes

───────────────────────────────────────────────────────────────────────

STEP 1: Generate Secrets (2 min)
───────────────────────────────────────────────────────────────────────

  Option A (Mac/Linux):
  $ bash scripts/setup-production.sh

  Option B (Windows PowerShell):
  $ [Convert]::ToBase64String([Security.Cryptography.RandomNumberGenerator]::GetBytes(32))

  ✏️  Save the JWT_SECRET output — you'll need it in Vercel


STEP 2: Push to GitHub (5 min)
───────────────────────────────────────────────────────────────────────

  $ cd C:\Users\Administrateur\mojazine-saas
  $ git push -u origin master

  📍 Repository: https://github.com/affanesalim1-bot/Control-tower


STEP 3: Create AWS RDS Database (15 min)
───────────────────────────────────────────────────────────────────────

  1. Go to: https://console.aws.amazon.com/rds/
  2. Click: "Create database"
  3. Select: PostgreSQL 15
  4. Instance: db.t3.micro
  5. Name database: mojazine_db
  6. Set master password: [STRONG_PASSWORD]
  7. Click: "Create database"
  8. ⏳ Wait 10 minutes for creation
  9. 📋 Copy endpoint when ready

  Example endpoint:
  mojazine.c1234567.us-east-1.rds.amazonaws.com


STEP 4: Deploy to Vercel (5 min)
───────────────────────────────────────────────────────────────────────

  1. Go to: https://vercel.com/dashboard
  2. Click: "New Project"
  3. Select: GitHub repository (Control-tower)
  4. Add Environment Variables:

     DATABASE_URL
     → postgresql://postgres:PASSWORD@ENDPOINT:5432/mojazine_db
       (Replace PASSWORD and ENDPOINT)

     JWT_SECRET
     → [From Step 1]

     NODE_ENV
     → production

     NEXT_PUBLIC_API_URL
     → https://[PROJECT].vercel.app

     NEXT_PUBLIC_SOCKET_URL
     → https://[PROJECT].vercel.app

  5. Click: "Deploy"
  6. ⏳ Wait for build (3-5 min)


STEP 5: Run Database Migration (2 min)
───────────────────────────────────────────────────────────────────────

  $ vercel env pull
  $ npx prisma migrate deploy

  Or manually via Vercel Console:
  → Deployments > Runtime logs > Check for migration output


STEP 6: Test Production (1 min)
───────────────────────────────────────────────────────────────────────

  ✅ Health Check:
  $ curl https://[PROJECT].vercel.app/api/health

  Expected response:
  {"status":"ok","database":"connected"}

  If database connection fails:
  → Check DATABASE_URL in Vercel Environment Variables
  → Verify RDS security group allows port 5432
  → Re-run: npx prisma migrate deploy
